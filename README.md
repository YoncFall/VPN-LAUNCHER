# VPN LAUNCHER BY @YoncFALL

Графический лаунчер для [sing-box](https://github.com/SagerNet/sing-box) на Windows.
Тёмный игровой интерфейс, два режима работы, ручные исключения для игр и античитов.

**Никаких серверов и подписок в комплекте.** Это только клиент — подписку приносишь ты сам.

## Возможности

- Подписки `vless` / `vmess` / `trojan` / `shadowsocks` / `hysteria2` / `tuic`
- Параллельный пинг всех серверов, сортировка по отклику
- **Режим «Весь трафик» (TUN)** — весь трафик системы идёт в туннель
- **Режим «Системный прокси»** — только браузер и приложения, уважающие прокси
- **Исключения процессов** — свой список плюс 25 встроенных (Steam, Rust, EAC, DayZ, BattlEye и другие)
- Автоподбор лучшего сервера, если ничего не выбрано
- Без установки драйверов, без службы, без автозапуска

## Системные требования

- Windows 10 1809 или новее (x64)
- PowerShell 5.1 (входит в состав Windows)
- [sing-box](https://github.com/SagerNet/sing-box) — входит в архив релиза, ставится автоматически

## Установка

Проще всего — скачать готовый архив из раздела
[Releases](https://github.com/yoncfall-tech/VPN-LAUNCHER/releases) и запустить
в нём `install.bat`. `sing-box.exe` уже внутри.

Если собираешь из исходников клонированием:

1. Скачай `sing-box.exe` для Windows x64 со страницы
   [релизов sing-box](https://github.com/SagerNet/sing-box/releases)
2. Положи его в папку `bin\` рядом с исходниками
3. Запусти `install.bat`

Ярлык появится на рабочем столе и в меню «Пуск».

При первом запуске вставь **свою** ссылку-подписку и нажми **«Загрузить подписку»**.
Подписок в сборке нет — клиент работает с тем, что введёшь ты.

## Как пользоваться

| Шаг | Что делать |
|-----|-----------|
| 1 | Вставить ссылку-подписку, **Загрузить подписку** |
| 2 | **Проверить пинг** — посмотреть, кто быстрее отвечает |
| 3 | Выбрать сервер (или ничего не выбирать — тогда возьмёт лучший) |
| 4 | Выбрать режим: TUN или системный прокси |
| 5 | **ПОДКЛЮЧИТЬСЯ** |

Режим TUN требует прав администратора — приложение спросит и перезапустится само.

### Исключения из туннеля

В режиме TUN через туннель идёт **весь** трафик, включая игры. Чтобы Steam, игровые
клиенты и античиты выходили напрямую, есть два списка:

- **Встроенный** — 25 процессов, их добавлять не нужно: Steam, `RustClient.exe`,
  `EasyAntiCheat*`, `DayZ*`, `BEService*`, `Phasmophobia.exe`, `REPO.exe`,
  `ONCE_HUMAN.exe`, `GTA5*`, `ragemp_v.exe`, `cs2.exe`
- **Свой** — кнопка «Добавить» и выпадающий список всех запущенных процессов.
  Можно вписать имя `.exe` руками. Список сохраняется.

> Исключения работают только в режиме **TUN**. В режиме системного прокси игры
> обычно и так ходят напрямую, мимо прокси.

## Удаление

Запусти `uninstall.bat` — удалит ярлыки, настройки, логи и остановит sing-box.

## Как это работает

Лаунчер сам по себе не занимается VPN. Он генерирует конфиг sing-box и запускает
его как отдельный процесс. Наружу он торчит либо системным прокси, либо виртуальным
TUN-адаптером (драйвер Wintun входит в поставку sing-box).

```
VPN.ps1  ──▶  theme.ps1  оформление
    │
    ├──▶  core.ps1  парсер подписок + генерация config.json
    │                  └──▶  sing-box.exe  (отдельный процесс, GPL-3.0)
    │
    └──▶  state.json  подписка, выбранные серверы, исключения
```

- Проект не связан со Steam, Valve и SagerNet.

## Честное предупреждение

Никакой VPN не даёт гарантии от блокировки в играх. Риск обычно связан не с самим
клиентом, а с тем, что адрес IP общий с другими людьми или находится в регионе,
который у игры нелюбим. Смягшить можно только так: пустить игру и античиты напрямую
(для этого здесь и сделаны исключения) и не менять регион при подключении.
