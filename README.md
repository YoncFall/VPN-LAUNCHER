# VPN LAUNCHER BY @YoncFALL

Графический лаунчер для [sing-box](https://github.com/SagerNet/sing-box) на Windows.
Тёмный игровой интерфейс, два режима работы, ручные исключения для игр и античитов.

**Никаких серверов и подписок в комплекте.** Это только клиент — подписку приносишь ты сам.

## Возможности

- Подписки `vless` / `vmess` / `trojan` / `shadowsocks` / `hysteria2` / `tuic`
- Параллельный пинг всех серверов, сортировка по отклику
- **Режим «Весь трафик» (TUN)** — весь трафик системы идёт в туннель
- **Режим «Системный прокси»** — только браузер и приложения, уважающие прокси
- **Исключения процессов** — свой список плюс 25 встроенных (Steam, Rust, EAC, DayZ, BattlEye и другие)
- Автоподбор лучшего сервера, если ничего не выбрано
- Без установки драйверов, без службы, без автозапуска

## Системные требования

- Windows 10 1809 или новее (x64)
- .NET Framework 4.x (входит в состав Windows, отдельно ставить не нужно)
- [sing-box](https://github.com/SagerNet/sing-box) — входит и в установщик, и в архив

## Установка

**Обычный путь:** скачай `VPN-LAUNCHER-1.0.3-Setup.exe` из
[Releases](https://github.com/yoncfall-tech/VPN-LAUNCHER/releases), запусти, нажми
«Установить». Программа встаёт в `%LOCALAPPDATA%\Programs\VPNLauncher`, ярлык
появляется на рабочем столе и в меню «Пуск», а в «Программы и компоненты» —
строка «VPN ЛАУНЧЕР BY @YoncFALL» с кнопкой удаления.

Права администратора установщику **не нужны**: он ставит программу в профиль
пользователя. Администратор может спросить только сам клиент в момент подключения
в режиме TUN.

Ключи установщика, если нужно без окна:

| Ключ | Что делает |
|------|-----------|
| `/S` | тихая установка, без вопросов |
| `/DIR="C:\путь"` | поставить в свою папку |
| `/NOICONS` | не создавать ярлыки (существующие не трогает) |
| `/NORUN` | не запускать после установки |
| `/UNINSTALL` | удалить программу |

**Для тех, кто любит zip:** архив `VPN-LAUNCHER-1.0.3.zip` тоже в Releases, там
работает `install.bat` из папки `setup`. `sing-box.exe` уже внутри.

### Сборка из исходников

1. Скачай `sing-box.exe` для Windows x64 со страницы
   [релизов sing-box](https://github.com/SagerNet/sing-box/releases)
2. Запусти `build-exe.ps1` — соберётся `bin\VPNLauncher.exe`
3. Запусти `build-installer.ps1 -Version 1.0.3` — соберётся
   `dist\VPN-LAUNCHER-1.0.3-Setup.exe`
4. Либо `build-release.ps1 -Version 1.0.3` для zip-архива

Из внешних программ нужен только .NET Framework, который уже есть в Windows.

## Про запуск

`VPNLauncher.exe` — это не обёртка над консолью, а сама программа. Интерфейс
рисуется внутри этого процесса, поэтому:

- в панели задач и в Alt+Tab **наша иконка**, а не значок PowerShell
- чёрного окна консоли нет вообще
- в диспетчере задач нет отдельного процесса `powershell.exe`
- повторный клик по ярлыку не открывает второе окно, а выводит уже запущенное

Движок PowerShell при этом используется системный, ничего доставлять не нужно.

При первом запуске вставь **свою** ссылку-подписку и нажми **«Загрузить подписку»**.
Подписок в сборке нет — клиент работает с тем, что введёшь ты.

## Как пользоваться

| Шаг | Что делать |
|-----|-----------|
| 1 | Вставить ссылку-подписку, **Загрузить подписку** |
| 2 | **Проверить пинг** — посмотреть, кто быстрее отвечает |
| 3 | Выбрать сервер (или ничего не выбирать — тогда возьмёт лучший) |
| 4 | Выбрать режим: TUN или системный прокси |
| 5 | **ПОДКЛЮЧИТЬСЯ** |

Режим TUN требует прав администратора — приложение спросит и перезапустится само.

### Исключения из туннеля

В режиме TUN через туннель идёт **весь** трафик, включая игры. Чтобы Steam, игровые
клиенты и античиты выходили напрямую, есть два списка:

- **Встроенный** — 25 процессов, их добавлять не нужно: Steam, `RustClient.exe`,
  `EasyAntiCheat*`, `DayZ*`, `BEService*`, `Phasmophobia.exe`, `REPO.exe`,
  `ONCE_HUMAN.exe`, `GTA5*`, `ragemp_v.exe`, `cs2.exe`
- **Свой** — кнопка «Добавить» и выпадающий список всех запущенных процессов.
  Можно вписать имя `.exe` руками. Список сохраняется.

> Исключения работают только в режиме **TUN**. В режиме системного прокси игры
> обычно и так ходят напрямую, мимо прокси.

## Удаление

«Пуск» → «Программы и компоненты» → **VPN ЛАУНЧЕР BY @YoncFALL** → «Удалить».
То же самое делает ярлык «Удалить VPN ЛАУНЧЕР» в меню «Пуск», или
`uninstall.exe /UNINSTALL` в папке программы. Удаление снимает ярлыки, запись
из списка программ и саму папку. Если ставил из zip — запусти `uninstall.bat`.

## Как это работает

`VPNLauncher.exe` — обычный GUI-процесс. Он читает `VPN.ps1` и выполняет его
внутри себя через встроенный движок PowerShell, поэтому окно принадлежит ему, а
не `powershell.exe`. Дальше лаунчер генерирует конфиг sing-box и запускает его как
отдельный процесс. Наружу он торчит либо системным прокси, либо виртуальным
TUN-адаптером (драйвер Wintun входит в поставку sing-box).

```
VPNLauncher.exe  (своё окно, своя иконка, без консоли)
   │
   ├──▶ VPN.ps1  ──▶  theme.ps1  оформление
   │        │
   │        ├──▶  core.ps1  парсер подписок + генерация config.json
   │        │                  └──▶  sing-box.exe  (отдельный процесс, GPL-3.0)
   │        │
   │        └──▶  state.json  подписка, выбранные серверы, исключения
   │
   └──▶ app.pid  для единственного экземпляра
```

## Честное предупреждение

Никакой VPN не даёт гарантии от блокировки в играх. Риск обычно связан не с самим
клиентом, а с тем, что адрес IP общий с другими людьми или находится в регионе,
который у игры нелюбим. Смягшить можно только так: пустить игру и античиты напрямую
(для этого здесь и сделаны исключения) и не менять регион при подключении.
