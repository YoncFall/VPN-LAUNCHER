zapret (winws) - included binary component
============================================

This launcher bundles winws.exe, the Windows build of the zapret project
by bol-van and contributors, licensed under GNU GPL v3. It is NOT part
of the VPN LAUNCHER source code.

Source    : https://github.com/bol-van/zapret
Provenance: official release v72.13, binaries/windows-x86_64/winws.exe,
built by the project's CI from the tagged source. Its SHA-256 (and the
SHA-256 of the companion files) was verified against the official
sha256sum.txt published in the same release. Exact hashes and the full
verification story: zapret/VERSION.txt.

winws is a Cygwin program: bin/cygwin1.dll comes from the same official
release and is also hash-verified there.

WinDivert (https://github.com/basil00/WinDivert), the packet divert
driver used by winws (bin/WinDivert.dll, bin/WinDivert64.sys), is
distributed under LGPL-3.0 (full text: LICENSE-WinDivert.txt). The
bundled binaries are the WinDivert 2.2.2 files from the same zapret
release; they are byte-identical to the author's own v2.2.2 release
(https://github.com/basil00/WinDivert/releases/tag/v2.2.2), and
WinDivert64.sys passes Authenticode verification (valid signature).

The fake payload packets (bin/*.bin) are generated by this project's own
script tools/zapret/gen_payloads.py; they are deterministic (regenerating
reproduces the recorded hashes). The host lists (lists/*.txt) are this
project's own as well.

If you redistribute this program you must keep these files, keep winws
and WinDivert unmodified, and offer the corresponding source of all
three components:

  zapret    : https://github.com/bol-van/zapret (tag v72.13)
  WinDivert : https://github.com/basil00/WinDivert (tag v2.2.2)
  launcher  : https://github.com/YoncFall/VPN-LAUNCHER
