# Changelog

Все заметные изменения проекта **VPN LAUNCHER BY @YoncFALL**.

Проект придерживается [семантического версионирования](https://semver.org/lang/ru/).
Формат записей — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.0.6] — 2026-09-28

### Исправлено
- **Запуск на чистой Windows.** Раньше на машинах с политикой выполнения
  сценариев `Restricted` (стандарт для свежей Windows) программа падала при
  старте с ошибкой «выполнение сценариев отключено». Теперь `core.ps1` и
  `theme.ps1` загружаются текстом в память и от политики не зависят совсем.
- **Корень данных.** `sing-box.exe`, конфиг и лог ищутся в папке программы,
  а не уровнем выше. Работает в обеих раскладках: плоской (установщик) и `src\`
  (zip-архив).
- **Версия установщика** теперь совпадает с номером релиза (раньше при имени
  файла `1.0.6` внутри заявлялась `1.0.5`) — подставляется автоматически при
  сборке.
- В сгенерированный конфиг добавлено обязательное поле `action: "route"` в
  правила маршрутизации — конфиг соответствует актуальной схеме sing-box.

### Что нового
- sing-box **1.14.2** в комплекте (sha256 `7bbef1dea9189ee12799ae834ea4b465`).

### Под капотом
- Состояние пинга инициализируется при старте, а не только по нажатию кнопок.
- `install.bat` / `uninstall.bat` приведены к корректным кодировкам (ASCII без
  BOM, кириллица — с BOM).
- `uninstall.bat` завершает только процессы самой программы (по точному пути),
  не трогая чужой `sing-box.exe` других приложений.

## [1.0.3] — 2026-09-28

- Нативный хост `VPNLauncher.exe` вместо командной строки: своё окно, своя

- Первый выпуск: графический лаунчер sing-box для Windows (GPL-3.0).

- Режимы «Весь трафик (TUN)» и «Системный прокси».
- Исключения процессов (встроенный список + свой).
